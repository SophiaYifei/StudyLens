Time Series Decomposition
We can decompose a time series into three main components:
Trend
Seasonality
Residuals
They are combined using the additive or multiplicative model
Additive:
Multiplicative:
Additive vs. Multiplicative
Additive model:
Linear trend
Constant seasonal periods over time
Multiplicative model:
Non-linear trend
Width or height of seasonal periods changes over time
Decomposing Time Series
We can use the seasonal_decompose() function from the statsmodels package to decompose time series into their trend, seasonal, and residual components
We must select additive or multiplicative time series and input the estimated period
Be careful about automated time series decomposition
It may do well at identifying trend, but sometimes finds seasonal patterns that don’t really exist
Autocorrelation
Autocorrelation is the correlation of a signal with a delayed (lagged) copy of itself
Detected using the Durbin-Watson test or using the Pearson correlation coefficient of the two series (actual and lagged)
Autocorrelation is an indicator of seasonality
Markov Processes
A process with full autocorrelation with a lag = 1 is called a Markov process or a Markov chain
The current state depends only on the state attained at the previous timestep
A transition matrix specifies the probabilities of shifting between states
Markov models are used in the sciences, predicting stock market prices, and ranking web search results (PageRank)
https://en.wikipedia.org/wiki/Markov_chain
Autoregression Model
If we identify strong correlation with the past, we can build a model using the past values as features
This is called an autoregression model
We can create features using past data at one lag or multiple
