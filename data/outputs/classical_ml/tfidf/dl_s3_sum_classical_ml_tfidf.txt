Using pre-trained models
Select and load an existing pre-trained model
Freeze the model weights (turn autograd off)

Train the model as normal, which trains only the final layer weights

We have objects of varying size/shape/location in the image
We take thousands of patches of the image of different sizes/shapes, make a prediction for each and keep only the best
These patches of varying size/shape/location are called anchor boxes
We can set the anchor box size/shape range or determine it from our training data (e.g. large objects or small)
1% of the anchor boxes in RetinaNet
If we make predictions for every anchor box, many will be low probability and many will be overlapping
Issue:
Keep only the best ones:
Remove all predicted boxes that have a detection probability less than a confidence threshold we set
Eliminate duplicate boxes which refer to the same object
Calculate the Intersection over Union value for each pair of boxes and eliminate one when IoU is above a certain threshold
The box we keep is the one with the higher detection probability

YOLOv3
The primary benefit of YOLO v3 was reasonably high performance with very quick inference (can even run almost real-time)
Paper
“Region proposals”
3 stage pipeline:
Generates ~2000 region proposals using selective search
Warps or crops each region proposal to a standard size (227x227) before feeding it through a pre-trained CNN (originally AlexNet)
Extracts CNN features from each proposed region
Classifies each region with SVMs
Bounding box (bbox) regressor predicts scale offset adjustments for x,y, width and height, refining the initial region proposals to better fit the actual objects
R-CNN (Regions with CNN features)
Image Source
Issues:
CNN features must be computed for each region proposal independently → training and inference are slow
CNN features need to be cached for each region proposal from all training images to train the SVMs → requires significant storage space
R-CNN (Regions with CNN features)
Replaced the slow selective search with a neural network to generate proposals
Uses anchor boxes - predefined boxes of different scales and aspect ratios at each position
R-CNN required separate training stages for CNN features, SVMs, and bbox regression. Faster R-CNN can be trained end-to-end with a multi-task loss
Faster R-CNN
Instead of computing CNN features for each region proposal separately:
Computes features for the entire image once
Uses RoI Pooling to extract features for each proposal from the shared feature map

U-Net
Paper (2015)
Main Idea:
labels each pixel in an image with its corresponding class
U-Net
Paper (2015)
Contracting path (encoder) uses repeated blocks of convolution and max pooling operations to capture hierarchical features:
reducing spatial dimensions while increasing the number of feature channels
U-Net
Paper (2015)
Expanding path (decoder) uses upsampling operations followed by convolutions to restore spatial resolution: combines high-level semantic information with fine-grained spatial details from the encoder through skip connections
U-Net
Paper (2015)
Skip connections concatenate feature maps from the encoder to corresponding decoder layers:
preserve fine spatial details that would otherwise be lost during downsampling and enabling more accurate segmentation boundaries
U-Net
Paper (2015)
The final layer uses a 1x1 convolution to map the feature vector to the desired number of classes, followed by a pixel-wise softmax activation to produce class probability maps for each pixel

Vision Transformers
Adapt the transformer architecture from NLP to handle image processing tasks
Treat images as sequences of patches, similar to how text transformers process sequences of words
Vision Transformers (ViT)
Paper, 2021
“Visual tokens”  → word tokens
Images are divided into fixed-size patches (typically 16x16 pixels)
Each patch is flattened into a 1D vector and linearly embedded
Position embeddings are added to maintain spatial information
Vision Transformers (ViT)
Paper, 2021
Standard Transformer encoder blocks:
Multi-head self-attention to capture relationships between patches
MLP blocks with GELU activation
Layer normalization and residual connections
Vision Transformers (ViT)
Paper, 2021
Multi Head Attention - what it allows
Each patch can attend to (pay attention to) all other patches in the image
Attention weights reveal which parts of the image are relevant for the model's decisions
Multiple attention heads learn different types of relationships between patches
Vision Transformers (ViT)
Paper, 2021
Advantages:
Global receptive field from the start
Strong performance on large datasets
More flexible architecture for multi-modal tasks
Challenges:
Computationally intensive for high-resolution images
Requires large datasets for training
May miss fine-grained local features that CNNs naturally capture
