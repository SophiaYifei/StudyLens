# NLP Lecture Summary: Transformers and Attention Mechanisms

## Key Preprocessing Steps
**Tokenization**: Use model-specific tokenizers (BERT tokenizer for BERT, GPT tokenizer for GPT models). **Stop Word Removal**: Remove common words with little semantic value to help models focus on meaningful content.

## Attention Mechanisms
**Self-Attention**: Improves word embeddings by adding context from surrounding words in the same sequence. Uses three components:
- **Query (Q)**: What information the current word seeks
- **Keys (K)**: What information other words provide  
- **Values (V)**: The actual content to be weighted

Process: Compute dot product between queries and keys → normalize scores → create weighted sum of values → produce contextualized embeddings.

**Multi-Head Attention**: Runs multiple attention mechanisms in parallel, each learning different types of relationships (syntax, semantics, etc.). Outputs are concatenated and projected through a dense layer.

**Cross-Attention**: Used between two different sequences (e.g., translation tasks). Queries come from one sequence, keys and values from another, enabling selective focus on relevant parts.

## Transformer Architecture
Based on the "Attention is All You Need" (2017) paper. Three main types:
- **Encoder-only** (BERT): Bidirectional, good for understanding tasks
- **Decoder-only** (GPT): Autoregressive, good for text generation  
- **Encoder-Decoder** (T5, BART): Best for sequence-to-sequence tasks

Key components include multi-head attention, feed-forward networks, residual connections, and layer normalization. Token limits exist due to quadratic complexity O(n²) of attention computation.

## Applied NLP Applications
**Text Similarity**: Measures lexical (vocabulary-based) or semantic (meaning-based) similarity by comparing embeddings. **Text Summarization**: Requires careful evaluation methods. **Topic Modeling**: Groups documents by themes.

The Hugging Face Transformers library provides three building blocks: tokenizer, transformer architecture, and task-specific heads for classification, generation, and other NLP tasks.
