### Summary of Lecture Material: Modeling Process & Algorithms

#### Context and Introduction
- **Wagstaff's Quote**: Emphasizes the complexity of implementing machine learning solutions in real-world contexts.
- **Course Overview**:
  - **Core Topics**: Supervised and unsupervised learning, regression, classification, and key algorithms.
  - **Process Focus**: Identifying problems, selecting algorithms, evaluating models, interpreting results, and applying ML to structured data.

#### Key Concepts
- **Machine Learning Definition**: Ability to gain skills or knowledge through experience.
- **Supervised vs. Unsupervised Learning**:
  - **Supervised**: Known inputs (features) and outputs (labels).
    - **Regression**: Predicts numerical values.
    - **Classification**: Predicts categories.
  - **Unsupervised**: Only inputs (features), no labels.

#### Real-World Applications
- **Heuristics vs. ML**:
  - **Heuristics**: Simple rules based on past experience.
  - **ML**: Adaptable, scalable, and learns from data.
  - **Baseline Importance**: Always start with a simple heuristic or baseline model.

#### Algorithm Selection Best Practices
- **No Free Lunch Theorem**: No single algorithm universally outperforms others.
- **Occam's Razor**: Prefer simpler models if other things are equal.
- **Tradeoffs**:
  - **Performance**
  - **Interpretability**
  - **Computational Cost**

#### Model Evaluation
- **Train/Test Split**: Divide data into training, validation, and test sets.
- **Avoid Overfitting**: Ensure model generalizes well to unseen data.
- **Cross-Validation**: Techniques like k-folds to estimate model performance accurately.
- **Bias-Variance Tradeoff**: Balance simplicity and complexity to avoid overfitting.
- **Metrics**:
  - **Regression**: Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), Coefficient of Determination (R²).
  - **Classification**: Accuracy, Precision, Recall, F1 Score, AUROC, PR Curve.

#### Sampling and Data Leakage
- **Random Sampling**: Important for unbiased model evaluation.
- **Stratified Sampling**: Ensures balanced representation of subgroups.
- **Weighted Sampling**: Adjusts for imbalanced data.
- **Data Leakage**: Avoid using future data in training, ensure proper preprocessing steps.

#### Feature Selection and Encoding
- **Feature Removal**: Remove high-null features, reduce multicollinearity.
- **Feature Selection Methods**: Use SelectKBest, Random Forest feature importance.
- **Encoding**: Ordinal, one-hot encoding; avoid artificial ordering.
- **Scaling**: StandardScaler vs. MinMaxScaler; scale before regularization.

#### Handling Class Imbalance
- **Accuracy Trap**: Misleading when dealing with imbalanced data.
- **Techniques**: Oversampling, undersampling, fixing root causes.

#### Pipelines
- **Purpose**: Prevent data leakage, ensure reproducibility, cleaner workflows.
- **Implementation**: Use `sklearn` pipelines.

#### Practical Tips
- **Problem Statement Writing**: Practice before diving into modeling.
- **Baseline Models**: Always start with simple heuristics or baseline models.
- **Cross-Validation**: Use k-folds for reliable performance estimates.
- **Bias-Variance Tradeoff**: Plot validation curves to find sweet spots.
- **Metrics**: Consider scale effects and choose appropriate metrics.
- **Feature Engineering**: Inspect selected features manually.
- **Imbalanced Data**: Address imbalances effectively.

### Conclusion
- **Holistic Approach**: Emphasis on the entire modeling process, from problem identification to deployment.
- **Critical Thinking**: Encourage reflection on whether heuristics can solve problems instead of ML.
- **Practical Application**: Focus on real-world structured data and structured problem-solving.
