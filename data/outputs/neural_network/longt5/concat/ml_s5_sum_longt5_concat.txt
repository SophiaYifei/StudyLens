In this chapter, the students learn how to predict classes using a class-based approach. They use a logistical regression model to calculate the cost function and then use it to predict the predicted values for each class. For example, if there are two classes, one class is assigned as the closest train point and the other as the nearest neighbor. If there are several classes, they assign the least number of points in order to get the best result. The first part of the class will consist of an assessment of the performance of three different algorithms. In this chapter, the UM introduces a new approach to finding the minimum of negative log likelihood in a logistic regression model. The UM uses a method called gradient descent to find the best value for each step along a given curve. He then discusses how it can be used to predict future events using a cost-or-loss function.
