Rivers shows how convolutional learning can be used to learn information from images. He describes a sliding window technique that captures changes in the image and reduces the size of training by using weights. It's particularly useful when large datasets need to be trained because it can save time. This chapter introduces two new architectures: an "inception model" and an "artificial learning" technique called transfer learning. Each node will have its own weights, which can be adjusted during training. Then they'll all use different weights to build the same architecture.
