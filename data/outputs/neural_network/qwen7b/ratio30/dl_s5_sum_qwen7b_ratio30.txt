### Detailed Topics Covered

#### Attention & Transformers

**Attention Fundamentals**

- **Self-Attention**
  - **Dot Product Attention**: 
    \[
    \text{score}(i,j) = v_i \cdot v_j
    \]
  - **Softmax Normalization**:
    \[
    w(i,j) = \frac{\exp(\text{score}(i,j)/\sqrt{d_k})}{\sum_{j'} \exp(\text{score}(i,j')/\sqrt{d_k})}
    \]
  - **Weighted Sum**:
    \[
    Y_i = \sum_j w(i,j) \times v_j
    \]

- **Multi-Head Attention**
  - **Query, Key, Value Matrices**:
    \[
    Q = v \times W_Q, \quad K = v \times W_K, \quad V = v \times W_V
    \]
  - **Concatenation and Dense Layer**:
    \[
    \text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_H) \times W_O
    \]

- **Cross-Attention**
  - **Query Sequence**: Computes attention scores based on its relationship with every element in the key-value sequence.

**Transformer Architecture**

- **Encoder-Decoder Structure**
  - **Encoder**: Processes input text through self-attention, produces context-rich representations.
  - **Decoder**: Generates output sequence, uses masked self-attention and cross-attention.

- **Feed Forward Network**: Adds and normalizes the output.

- **Positional Encoding**: Adds position information to embeddings.

- **Masking**: Prevents tokens from attending to future tokens in the sequence.

- **Layer Normalization**: Normalizes across feature dimensions.

#### Applied NLP Techniques

**Text Similarity**

- Lexical Similarity: Similar vocabulary.
- Semantic Similarity: Similar meaning.
- Calculating Similarity Using Embeddings.

**Text Summarization**

- Extractive Summarization: Selects sentences from the original text.
- Abstractive Summarization: Generates new text retaining key points.

**Topic Modeling**

- Traditional Methods: LSA, LDA.
- Deep Learning Approaches: Transformer Embeddings.

#### Advanced Topics

**Visualizing Embedding Spaces**

- Dimensionality Reduction Techniques: PCA, t-SNE, UMAP.
- Measuring Similarity: Cosine Similarity, Euclidean Distance, Jaccard Similarity.

**Large Language Models (LLMs)**

- Scale Laws: Loss decreases with more data, parameters, and compute.
- Emergent Abilities: Few-shot learning, chain-of-thought reasoning.
- Examples: GPT-4, Claude, Gemini.

**Multimodal Models**

- CLIP (Contrastive Learning for Image and Text): Joint image-text encoder.
- Visual Question Answering: Image encoder (ViT) + LLM decoder.

### Key Formulas

- **Self-Attention Score**:
  \[
  \text{score}(i,j) = v_i \cdot v_j
  \]
- **Self-Attention Weight**:
  \[
  w(i,j) = \frac{\exp(\text{score}(i,j)/\sqrt{d_k})}{\sum_{j'} \exp(\text{score}(i,j')/\sqrt{d_k})}
  \]
- **Self-Attention Output**:
  \[
  Y_i = \sum_j w(i,j) \times v_j
  \]
- **Scaled Dot-Product Attention**:
  \[
  \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) \times V
  \]
- **Multi-Head Attention**:
  \[
  \text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_H) \times W_O
  \]
  where \(\text{head}_i = \text{Attention}(Q@W_Q^i, K@W_K^i, V@W_V^i)\).

### BERT (Bidirectional Encoder Representations from Transformers)
- **Architecture**: BERT is an encoder-only model, meaning it processes the input text in a bidirectional manner.
- **Context Understanding**: BERT considers the context from both left and right sides of a word, allowing it to capture bidirectional dependencies effectively.
- **Pre-training Objective**: BERT is pre-trained using two objectives: Masked Language Modeling (MLM) and Next Sentence Prediction (NSP).
  - **MLM**: Randomly masks some tokens and predicts them.
  - **NSP**: Predicts whether the second sentence follows the first one logically.
- **Fine-Tuning**: BERT requires fine-tuning on downstream tasks to adapt to specific tasks like classification, named entity recognition, etc.
- **Strengths**: Excellent at understanding context and capturing bidirectional dependencies, making it particularly strong for tasks requiring deep understanding of context.

### GPT (Generative Pre-trained Transformer)
- **Architecture**: GPT is a decoder-only model, meaning it processes the input text in a unidirectional manner (left-to-right).
- **Context Understanding**: GPT focuses on understanding the context from the left side of the text, which can sometimes lead to limitations in capturing long-term dependencies.
- **Pre-training Objective**: GPT is pre-trained using a single objective: Next Token Prediction (NLP).
  - **NLP**: Predicts the next token in a sequence.
- **Fine-Tuning**: GPT can be fine-tuned on various tasks like text generation, text completion, summarization, etc.
- **Strengths**: Good at generating coherent text and handling long-term dependencies, making it suitable for tasks involving text generation and completion.

### Key Differences
- **Directionality**: BERT is bidirectional, while GPT is unidirectional.
- **Objective**: BERT uses MLM and NSP, whereas GPT uses NLP.
- **Task Suitability**: BERT excels in tasks requiring deep context understanding, while GPT shines in text generation and completion tasks.
- **Fine-Tuning Requirements**: BERT often requires fine-tuning for specific tasks, while GPT can be directly fine-tuned for various downstream tasks.

These differences highlight the strengths and weaknesses of each model, making them suitable for different types of natural language processing tasks.ienie
