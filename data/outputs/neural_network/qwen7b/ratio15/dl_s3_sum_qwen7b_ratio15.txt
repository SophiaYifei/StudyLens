### Summary of Lecture 3: Applied Computer Vision

#### Major Topics Covered:

1. **Image Classification**
   - **Models**: DenseNet, SqueezeNet, ResNet, Inception, VGG, AlexNet
   - **Key Concepts**:
     - **DenseNet**: Dense connections and feature reuse; pros: alleviates vanishing gradients, cons: memory-intensive, complex
     - **SqueezeNet**: Small CNN architecture; pros: efficient, small parameters
   - **Pre-trained Models**: 
     - Available in PyTorch Model Zoo and TensorFlow Model Garden
     - Workflow: Load, freeze, replace head, optional unfreeze and fine-tune

2. **Object Detection**
   - **Bounding Box Methods**: 
     - **YOLO (You Only Look Once)**: Grid-based, multiple anchor boxes, fast inference
     - **Faster R-CNN**: Region Proposal Network (RPN) for proposals, shared feature map, faster than R-CNN
   - **Concepts**:
     - Anchor boxes, Non-Maximum Suppression (NMS), Intersection Over Union (IoU)

3. **Semantic Segmentation**
   - **Methods**: U-Net, Mask R-CNN, DeepLab, SegNet
   - **Architecture**: U-Net uses encoder-decoder with skip connections to preserve spatial details
   - **Metrics**: Mean Intersection Over Union (mIoU), pixel accuracy, boundary F1 score

4. **Model Evaluation**
   - **Classification**: Accuracy, precision, recall, F1 score, AUC-ROC, confusion matrix
   - **Detection**: Mean Average Precision (mAP), IoU thresholds (0.5, 0.75, COCO 0.5:0.95)
   - **Segmentation**: Mean Intersection Over Union (mIoU), pixel accuracy, frequency-weighted IoU, boundary F1 score
   - **Error Analysis**: Qualitative analysis, condition slices

5. **Advanced Topics**
   - **Vision Transformers**: Adapt NLP transformers to image processing; treat images as sequences of patches
   - **Grounding DINO + SAM**: Zero-shot object detection, promptable masks
   - **Diffusion Models**: Gradually denoise data to generate high-quality images; text-conditioned diffusion, latent diffusion

### Summary Request

**Objective:** Summarize the key points about different object detection methods, specifically comparing YOLO, Faster R-CNN, and the R-CNN family. Include advantages and disadvantages of each method. Provide a brief explanation of anchor boxes and non-maximum suppression (NMS). 

### Key Points to Include:

1. **YOLO (You Only Look Once):**
   - **Overview**: Grid-based, multiple anchor boxes, fast inference.
   - **Advantages**: High performance, nearly real-time inference.
   - **Disadvantages**: Requires more complex architecture, limited to fixed grid sizes.

2. **Faster R-CNN:**
   - **Overview**: Region Proposal Network (RPN) for proposals, shared feature map, RoI pooling.
   - **Advantages**: Faster than R-CNN, more efficient.
   - **Disadvantages**: Slower than YOLO, requires separate training stages.

3. **R-CNN Family:**
   - **Overview**: R-CNN uses selective search for region proposals, slower than Faster R-CNN.
   - **Advantages**: Effective region proposal generation.
   - **Disadvantages**: Slow, requires significant storage space.

4. **Anchor Boxes:**
   - **Concept**: Predefined boxes of different sizes and aspect ratios at each position.
   - **Usage**: Used to make bounding box predictions centered within grid cells.

5. **Non-Maximum Suppression (NMS):**
   - **Concept**: Eliminates duplicate boxes referring to the same object.
   - **Process**: Calculates Intersection Over Union (IoU) and eliminates one when IoU exceeds a threshold.
