# Natural Language Processing Lecture Summary

## Preprocessing and Core Concepts

### 1. Tokenization
When working with pre-trained models, use their specific tokenizer (e.g., BERT tokenizer for BERT models, GPT tokenizer for GPT models). This ensures compatibility with the model's training methodology.

### 2. Stop Word Removal
Common words like "the," "is," "a," and "of" add minimal value to text understanding. These stopwords are typically removed so models can focus on meaningful content words. However, removal should be task-dependent as stopwords can be crucial for certain applications (e.g., "not" in sentiment analysis).

## NLP Libraries and Tools

The lecture covers three main libraries:
- **NLTK**: For tokenization and parts-of-speech tagging
- **spaCy**: For named entity recognition and dependency parsing  
- **Transformers (Hugging Face)**: For advanced tasks like sentiment analysis, text summarization, and text generation

The Transformers library provides state-of-the-art models (BERT, GPT-2, T5) with three core building blocks: a tokenizer, transformer architecture, and task-specific heads for various NLP applications.

## Attention Mechanisms

### Self-Attention
Self-attention improves word embeddings by adding contextual information. Using the example "bank of the river," the goal is to create better representations where each word (like "bank") incorporates context from surrounding words to disambiguate meaning.

The process involves:
1. Creating Query, Key, and Value matrices from input embeddings
2. Computing dot products between queries and keys to get attention scores
3. Normalizing scores and applying them as weights to values
4. Producing contextually-aware output embeddings

### Multi-Head Attention
Multiple attention mechanisms run in parallel, each learning different types of relationships. This allows the model to capture various aspects simultaneously - one head might focus on syntax while another captures semantic relationships.

### Cross-Attention
Unlike self-attention (which operates within a single sequence), cross-attention works between two different sequences. This is essential for tasks like machine translation, where words in one language need to attend to relevant words in another language, or text-to-image generation.

## Transformer Architecture

### Core Components
The transformer uses scaled dot-product attention with the formula incorporating a scaling factor of 1/√(dk) where dk is the embedding dimensionality. This prevents large dot products that could cause vanishing gradients in the softmax function.

### Encoder-Decoder Structure
- **Encoder**: Processes entire input simultaneously using bidirectional self-attention, producing contextual representations
- **Decoder**: Generates output token-by-token using masked self-attention and cross-attention to encoder outputs

Modern architectures include:
- **Encoder-only models** (BERT): Best for understanding tasks
- **Decoder-only models** (original GPT): Designed for text generation  
- **Encoder-decoder models** (current GPT, BART): Combine both approaches

### Technical Considerations
Token limits exist due to quadratic complexity O(n²) in attention computation. Various optimizations like sparse attention patterns, gradient checkpointing, and parallel processing help manage memory and computational constraints.

## Applied NLP

### Text Similarity
Measures document similarity through two approaches:
- **Lexical similarity**: Based on shared vocabulary
- **Semantic similarity**: Based on meaning, typically calculated using embedding similarity
