### Summary of Lecture on Natural Language Processing (NLP)

#### Introduction to NLP Tasks and Applications
- **Applications**: Search, Machine Translation, Text Classification, Sentiment Analysis, Text Summarization, Topic Modeling, Q&A, Chatbots, Text Generation, Multimodal Processing.
- **Challenges**:
  - Context-dependent meanings (e.g., "bank" as river bank vs. money bank).
  - Polysemous words (same word with different meanings).
  - Observations not independent (history matters).

#### Representing Text
- **Static Embeddings (e.g., Word2Vec)**: Fixed vectors for words, no context awareness.
- **Contextual Embeddings**: Improve upon static embeddings by incorporating context.
- **Attention Mechanism**: Allows models to weigh the importance of different words in a sentence.

#### Traditional NLP Methods
- **Bag of Words (BoW)**: Represents texts as word frequency counts.
- **TF-IDF**: Adjusts word frequencies based on document and corpus statistics.
- **N-Grams**: Higher-order n-grams capture more context but suffer from combinatorial explosion.

#### Modern NLP Models
- **Word2Vec**: Shallow neural network for learning dense word embeddings.
- **GloVe**: Global co-occurrence matrix-based embeddings.
- **FastText**: Incorporates subword information.
- **Transformers**: Address long-range dependencies using self-attention mechanisms.

#### Sequence Models
- **RNNs (Recurrent Neural Networks)**: Process tokens sequentially; suffer from vanishing gradient problem.
- **LSTMs (Long Short-Term Memory Networks)**: Add cell state and gates to mitigate vanishing gradient.
- **GRUs (Gated Recurrent Units)**: Simplified version of LSTMs.

#### Text Similarity and Summarization
- **Text Similarity**: Measured using cosine similarity.
- **Text Summarization**: Extractive vs. Abstractive; popular models like BART, T5, Pegasus.

#### Topic Modeling
- **LDA (Latent Dirichlet Allocation)**: Probabilistic model for topic discovery.
- **BERTopic**: Uses BERT embeddings and UMAP for better topic modeling.

#### Evaluation Metrics
- **Paraphrase Scores**: Low even if semantically correct.
- **NLI-Based Factual Consistency**: Checks if summary aligns with source.
- **TF-IDF**: Still widely used despite newer methods.

#### Multimodal Models
- **CLIP**: Joint image and text model.
- **LLaMA, GPT-4V**: Visual question answering and multimodal models.

#### Key Terms Cheat Sheet
- **Polysemy**: One word with multiple meanings.
- **Synonym**: Multiple words with the same meaning.
- **Tokenization**: Splitting text into units.
- **Stemming**: Crude suffix removal.
- **Lemmatization**: Dictionary-based root finding.
- **TF-IDF**: Term frequency-inverse document frequency.
- **BoW**: Word count vector without order.
- **N-grams**: Sequences of N words.
- **Word2Vec**: Shallow neural network for static embeddings.
- **CBOW**: Context to center word.
- **Skip-gram**: Center word to context.
- **OOV**: Out of vocabulary.
- **Static Embedding**: Same vector regardless of context.
- **Contextual Embedding**: Changes with surrounding words (transformers).
