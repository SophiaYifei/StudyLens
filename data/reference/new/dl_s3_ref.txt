# 1. Applied Computer Vision

## 1.1 Image Classification

### Task Definition

Image classification assigns a **single class label** to an entire image.

**Input:**
- Image of shape `H × W × 3` (RGB)
- Pixel values typically in `[0, 255]`, normalized before training

**Output:**
- Probability vector of size `C` (number of classes)
- Produced via **softmax**
  
Example:
- Dog: 0.82
- Cat: 0.11
- Bear: 0.06
- Bird: 0.01


### Real-World Applications

- **Domino’s Pizza Quality Scanner**
- **Google Dermatology Assist**
  
These systems use classification to automate quality control and diagnosis.

---

## 1.2 Classification Architectures

Previously discussed:
- **AlexNet**
- **VGG (11, 13, 16, 19)**
- **ResNet (18, 34, 101, 152)**
- **Inception v3**

New models introduced:

---

### DenseNet

**Core Idea:**  
Each layer connects to **every previous layer** via concatenation.

If there are `L` layers:
\[
\frac{L(L+1)}{2}
\]
direct connections.

**Mechanism:**
- Feature maps are **concatenated**, not added (unlike ResNet).
- Encourages **feature reuse**.

**Pros:**
- Alleviates vanishing gradient
- Strong feature propagation
- Improved information flow

**Cons:**
- High memory usage
- Complex and harder to tune

---

### SqueezeNet

Designed for **parameter efficiency**.

**Architecture:**
- **Squeeze layer:** 1×1 convolutions (reduces channel depth)
- **Expand layer:** mix of 1×1 and 3×3 convolutions

**Advantages:**
- Significantly fewer parameters
- Lower computation cost
- Similar idea to Inception modules

---

## 1.3 Pre-Trained (Foundation) Models

A **pre-trained model**:
- Trained on a large dataset (e.g., ImageNet)
- Used as a starting point for new tasks
- Often called a **foundation model**

Available in:
- PyTorch Model Zoo
- TensorFlow Model Garden

---

### Transfer Learning Workflow

1. **Load pre-trained model**
2. **Freeze weights** (disable autograd)
3. **Replace final fully connected layer**
4. Train only new classification head
5. Optionally:
   - Unfreeze some or all layers
   - Fine-tune entire model

Benefits:
- Faster convergence
- Less data required
- Lower compute cost

# 2. Object Detection

## Why Detection Instead of Classification?

- **Explainability**: shows where object is
- **Autonomy**: spatial awareness required for robotics, driving, etc.

---

## 2.1 Bounding Boxes

Each detection includes:

```python
{
 'bbox': [x, y, width, height],  # normalized [0,1]
 'class_id': 2,
 'confidence': 0.98
}
```
Alternate formats:

- `[x_min, y_min, x_max, y_max]`
- Separate lists for:
  - Bounding boxes
  - Class IDs
  - Confidence scores

---

## COCO Annotation Standard

The **COCO (Common Objects in Context)** dataset defines a widely used bounding box format:

\[
\text{bbox} = [x_{\text{top-left}}, y_{\text{top-left}}, \text{width}, \text{height}]
\]

Where:
- \( x, y \) are the **top-left coordinates**
- Width and height define box dimensions
- Values are often normalized to \([0,1]\)

COCO dataset statistics:
- >200,000 labeled images
- ~1.5 million object instances
- 80 object categories

Most modern detection models are pre-trained on COCO.

---

# Anchor Boxes

## Motivation

Objects vary in:
- Scale
- Aspect ratio
- Location

Instead of predicting arbitrary boxes directly, models use **anchor boxes**:
- Predefined boxes of various sizes and shapes
- Placed across the image grid
- Each anchor predicts:
  - Offset adjustments
  - Class
  - Confidence score

Anchor box sizes can:
- Be manually defined
- Be learned from training data

Large objects → larger anchors  
Small objects → smaller anchors

---

# Non-Maximum Suppression (NMS)

Because many anchors overlap:

1. Remove boxes with confidence below threshold.
2. Compute **Intersection over Union (IoU)** between overlapping boxes.
3. If IoU exceeds threshold:
   - Keep higher-confidence box
   - Suppress the other

---

## Intersection over Union (IoU)

\[
IoU = \frac{\text{Area of Overlap}}{\text{Area of Union}}
\]

- IoU close to 1 → high overlap (good detection)
- IoU close to 0 → poor alignment

IoU is used both:
- During evaluation
- During NMS

---

# YOLO (You Only Look Once)

## Core Concept

- Divide image into \( S \times S \) grid.
- Each grid cell predicts:
  - \( N \) bounding boxes
  - Class probabilities
  - Objectness score

Total predictions:
\[
S \times S \times N
\]

---

## YOLOv3 Details

- Uses **9 anchor boxes**
- Predicts offsets from anchor:
  - Center location within grid cell
  - Width adjustment
  - Height adjustment
- Also predicts class probabilities
- Backbone: **Darknet-53**
- Emphasizes fast, near real-time inference

Primary advantage:
- High speed with competitive accuracy

---

# R-CNN Family

## R-CNN

Pipeline:
1. Generate ~2000 region proposals (Selective Search)
2. Warp each region to fixed size
3. Extract CNN features (e.g., AlexNet)
4. Classify using SVM
5. Refine boxes via regression

Issues:
- Very slow (~47s per image)
- Requires feature caching
- Multi-stage training

---

## Faster R-CNN

Improvements:
- Replace selective search with **Region Proposal Network (RPN)**
- Compute feature map once per image
- Use **RoI Pooling** to extract region features
- End-to-end training via multi-task loss

Performance:
- ~0.2 seconds per image
- Eliminates feature caching

# Semantic Segmentation

## Definition

Assign a class label to **every pixel** in the image.

Output shape:
\[
H \times W \times 1
\]

---

## Instance Segmentation

Difference from semantic segmentation:

- Semantic: labels all pixels of same class identically
- Instance: distinguishes different objects of same class

Output:
- List of masks
- Each mask has:
  - Binary pixel map
  - Class ID
  - Confidence score

---

# U-Net Architecture

Designed for semantic segmentation.

## Encoder (Contracting Path)

- Convolution layers
- Max pooling
- Reduces spatial resolution
- Increases feature depth

## Decoder (Expanding Path)

- Upsampling
- Convolution layers
- Restores spatial resolution

## Skip Connections

- Concatenate encoder feature maps to decoder layers
- Preserve fine-grained spatial information

## Final Layer

- 1×1 convolution
- Pixel-wise softmax
- Produces per-class probability map

Other segmentation models:
- Mask R-CNN
- DeepLabV3+
- PSPNet
- SegNet

# Model Evaluation

## Classification Metrics

- **Accuracy**
\[
\frac{\text{Correct Predictions}}{\text{Total Predictions}}
\]

- **Precision**
\[
\frac{TP}{TP + FP}
\]

- **Recall**
\[
\frac{TP}{TP + FN}
\]

- **F1 Score**
\[
2 \cdot \frac{Precision \cdot Recall}{Precision + Recall}
\]

- AUC-ROC
- Confusion Matrix

Best practices:
- Stratified splits
- Per-class reporting
- Top-k accuracy (large class sets)
- Cross-validation (small datasets)

---

# Object Detection Evaluation

## Mean Average Precision (mAP)

Procedure:

1. Compute IoU for each predicted box.
2. Set IoU threshold (e.g., 0.5).
3. Classify predictions as TP or FP.
4. Build Precision–Recall curve.
5. Compute area under curve → Average Precision (AP).
6. Average AP across classes → mAP.

Common metrics:
- mAP@0.5
- mAP@0.75
- COCO mAP (0.5–0.95 averaged)

---

# Segmentation Evaluation

- **Mean IoU (mIoU)**
- Pixel Accuracy
- Mean Pixel Accuracy
- Frequency-weighted IoU
- Boundary F1 Score

Best practices:
- Report per-class IoU
- Evaluate small/medium/large objects separately

---

# General Evaluation Best Practices

- Qualitative failure analysis
- Visualization of predictions
- Evaluate under different conditions:
  - Lighting
  - Scale
  - Occlusion
- Report:
  - Inference time
  - Parameter count
  - FLOPs
  - Memory usage

Per-class metrics often reveal dataset bias.

# Advanced Topics

## Vision Transformers (ViT)

### Key Idea

- Split image into 16×16 patches.
- Flatten patches → tokens.
- Add positional embeddings.
- Feed into transformer encoder.

Architecture:
- Multi-head self-attention
- MLP with GELU activation
- Layer normalization
- Residual connections

Advantages:
- Global receptive field
- Multimodal flexibility

Challenges:
- High compute cost
- Large data requirement
- May miss fine local detail

Applications:
- Classification
- Detection
- Segmentation
- Generation
- Video understanding

# Diffusion Models

## Core Principle

Image generation via iterative **denoising**.

### Forward Process
Gradually add Gaussian noise.

### Reverse Process
Train model to remove noise step-by-step.

\[
x_{t-1} = \text{Denoise}(x_t)
\]

---

## Text-Conditioned Diffusion

- Encode text prompt.
- Inject via cross-attention into U-Net.
- Guide denoising toward desired image.

Examples:
- Stable Diffusion
- DALL·E
- Latent Diffusion

Latent diffusion:
- Operates in compressed latent space
- More computationally efficient
