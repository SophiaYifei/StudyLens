# Classification Models and Algorithms

## 1. Introduction to Classification

### Definition
**Classification** models predict a **categorical target variable**, as opposed to a continuous numeric value (regression).

### Examples
- Handwritten digit recognition  
- Benign vs. malignant tumors  
- Disease type classification  
- Next-word prediction in language models  

### Binary vs. Multiclass
- **Binary classification**: Two classes (e.g., 0/1).
- **Multiclass classification**: More than two classes (e.g., digit 0–9).
- Numerical targets can be converted into classes via **binning** (e.g., income ranges).

### Key Difference from Regression
- **Regression can extrapolate** beyond observed target values.
- **Classification cannot extrapolate** beyond trained classes.
  - A classifier trained on 100 flower species cannot predict a new unseen species—it must choose from known classes.

# Logistic Regression

## 2. Why Not Use Linear Regression for Classification?

If we apply linear regression to binary classification:

\[
\hat{y} = w_0 + w_1 x
\]

Problems:
- Outputs are **not bounded** between 0 and 1.
- Predictions like 1.7 or -0.4 are not valid probabilities.
- Requires arbitrary thresholding.
- Poor classification performance.

---

## 3. Core Idea of Logistic Regression

Instead of predicting the class directly, predict:

\[
P(y = 1 \mid x)
\]

### Sigmoid (Logistic) Function

\[
\sigma(z) = \frac{1}{1 + e^{-z}}
\]

Where:

\[
z = w^T x
\]

Properties:
- Maps any real number to (0,1)
- S-shaped curve
- Interpretable as probability

### Decision Rule

\[
\hat{y} =
\begin{cases}
1 & \text{if } P(y=1) \ge 0.5 \\
0 & \text{otherwise}
\end{cases}
\]

Threshold can be adjusted to trade off **precision and recall**.

---

## 4. Parameter Estimation via Maximum Likelihood

### Why Not Use SSE?

For logistic regression:
- SSE is **non-convex**
- No closed-form solution

Instead, use **Maximum Likelihood Estimation (MLE)**.

---

### Likelihood for One Observation

\[
P(y_i \mid x_i) =
\sigma(w^T x_i)^{y_i}
(1 - \sigma(w^T x_i))^{1 - y_i}
\]

This compact form works because:
- If \( y_i = 1 \), second term disappears
- If \( y_i = 0 \), first term disappears

---

### Likelihood for Entire Dataset

\[
L(w) = \prod_{i=1}^{N}
\sigma(w^T x_i)^{y_i}
(1 - \sigma(w^T x_i))^{1 - y_i}
\]

---

### Log-Likelihood

Products are hard to differentiate, so take log:

\[
\ell(w) =
\sum_{i=1}^{N}
\left[
y_i \log \sigma(w^T x_i)
+
(1-y_i) \log (1-\sigma(w^T x_i))
\right]
\]

---

### Negative Log-Likelihood (NLL)

We define cost function:

\[
J(w) = -\ell(w)
\]

This is the **binary cross-entropy loss**.

Properties:
- Convex
- No closed-form solution
- Requires iterative optimization

---

# Gradient Descent

## 5. Gradient Descent Algorithm

Goal: minimize cost function \( J(w) \)

Update rule:

\[
w := w - \eta \nabla J(w)
\]

Where:
- \( \eta \) = learning rate
- \( \nabla J(w) \) = gradient

### Learning Rate Effects

- Too small → slow convergence
- Too large → oscillation or divergence
- Proper tuning is critical

---

### Gradient for Logistic Regression

\[
\nabla J(w) =
\sum_{i=1}^{N}
(\hat{y}_i - y_i) x_i
\]

Update rule becomes:

\[
w := w - \eta \sum_{i=1}^{N} (\hat{y}_i - y_i)x_i
\]

---

## 6. Logistic Regression Properties

- Produces **probabilistic outputs**
- Linear decision boundary
- Linear combination of features
- No feature interactions unless manually added

### In Scikit-learn
- `model.predict()` → class labels
- `model.predict_proba()` → probabilities
- Uses iterative solvers internally
- Applies **L2 regularization** by default

---

# Multiclass Classification – Softmax Regression

## 7. Motivation

Binary logistic regression predicts:

\[
P(y = 1)
\]

For multiple classes, we need:

\[
P(y = k)
\quad \forall k \in \{1, \dots, K\}
\]

---

## 8. Softmax Function

Each class has its own weight vector \( w_k \).

Score:

\[
z_k = w_k^T x
\]

Softmax:

\[
P(y=k \mid x) =
\frac{e^{z_k}}
{\sum_{j=1}^{K} e^{z_j}}
\]

Properties:
- Outputs sum to 1
- Valid probability distribution

Prediction:

\[
\hat{y} = \arg\max_k P(y=k \mid x)
\]

---

## 9. Cross-Entropy Loss

\[
J(w) =
-\sum_{i=1}^{N}
\sum_{k=1}^{K}
y_{ik} \log P(y=k \mid x_i)
\]

Where:
- \( y_{ik} = 1 \) if observation belongs to class k

When \( K=2 \), cross-entropy reduces to NLL for logistic regression.

# K-Nearest Neighbors (KNN)

## 10. Overview

**Instance-based learning**
- No explicit model training
- Stores training data
- Classifies by majority vote among nearest neighbors

---

## 11. Algorithm

1. Choose \( k \)
2. Compute distance (e.g., Euclidean)
3. Select k nearest neighbors
4. Predict majority class

---

## 12. Hyperparameters

- Number of neighbors \( k \)
- Distance metric
- Feature scaling

### Bias-Variance Tradeoff

| k | Bias | Variance |
|---|------|----------|
| Small | Low | High |
| Large | High | Low |

- \( k=1 \): very jagged boundary (overfitting)
- Large \( k \): smoother boundary

---

## 13. Limitations

- Computationally expensive
- Memory intensive
- Requires feature scaling
- Poor scalability for large datasets

---

# Support Vector Machines (SVM)

## 14. Core Idea

Find hyperplane that:
- Separates classes
- Maximizes margin

### Margin

Distance between decision boundary and nearest points.

### Support Vectors

Points closest to margin:
- Define boundary
- Other points irrelevant

---

## 15. Hard Margin Optimization

For line:

\[
w^T x + b = 0
\]

Distance from point to line:

\[
\frac{|w^T x + b|}{||w||}
\]

Objective:

\[
\min \frac{1}{2} ||w||^2
\]

Subject to:

\[
y_i(w^T x_i + b) \ge 1
\]

Convex optimization → unique global minimum.

---

## 16. Soft Margin SVM

Data often not perfectly separable.

Introduce slack variables.

Hyperparameter \( C \):

- Large C → smaller margin, fewer training errors
- Small C → wider margin, more tolerance

Interpretation:
- \( 1/C \) = tolerance for misclassification

---

## 17. Kernel Trick

Map data to higher-dimensional space without explicit transformation.

Common kernels:

- Linear
- Polynomial
- Radial Basis Function (RBF)

### RBF Kernel

Measures similarity via distance from landmark:

\[
K(x,x') = \exp(-\gamma ||x-x'||^2)
\]

Used for complex nonlinear boundaries.

---

## 18. SVC in Scikit-learn

Steps:
1. Standardize data
2. Choose kernel
3. Tune \( C \)
4. Tune degree (polynomial)
5. Use cross-validation

---

## 19. Probabilistic Outputs

SVM does not inherently produce probabilities.

Use **Platt Scaling**:
- Fit logistic regression on SVM outputs
- Produces calibrated probabilities

---

# Algorithm Comparison

| Algorithm | Strengths | Weaknesses |
|------------|------------|------------|
| Logistic Regression | Simple, probabilistic, convex | Linear boundary |
| Softmax | Multiclass extension | Linear boundary |
| KNN | Flexible, nonlinear | Slow, memory heavy |
| SVM | Strong theory, powerful kernels | Slow on large data, no native probabilities |

---

# Key Conceptual Takeaways

- Logistic regression predicts probabilities using sigmoid.
- Use **MLE + NLL** instead of SSE.
- Softmax extends logistic regression to multiclass.
- Cross-entropy is preferred loss for classification.
- KNN is non-parametric and sensitive to k.
- SVM maximizes margin using convex optimization.
- Kernels allow nonlinear separation.
- Feature scaling is critical for KNN and SVM.
- Regularization controls model complexity.
- Threshold tuning affects precision/recall tradeoff.

---

# Practical Recommendations

- Always standardize data for KNN and SVM.
- Use cross-validation to tune:
  - k (KNN)
  - C (SVM)
  - Kernel parameters
- Evaluate with precision, recall, F1—not just accuracy.
- Logistic regression is a strong baseline.
- SVM works well for high-dimensional “short and fat” datasets.
- KNN is useful for nonlinear problems but costly at scale.
