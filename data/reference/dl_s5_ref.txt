## 1. Representing Text: From Static to Contextual Embeddings

### Static Word Embeddings (e.g., Word2Vec)
- Represent each word as a fixed vector.
- Example:
  - *“bank of the river”*  
  - *“deposited money at the bank”*
- In Word2Vec, **“bank”** has the same embedding in both sentences.
- **Limitation:** No contextual awareness (cannot handle polysemy).

### Motivation
We need **contextual embeddings**:
- Word meaning should depend on surrounding words.
- This motivates the **attention mechanism** and the **Transformer architecture**.

---

# 2. Self-Attention

## Goal
Given original embeddings:

\[
v_1, v_2, \dots, v_n
\]

Produce improved contextual embeddings:

\[
y_1, y_2, \dots, y_n
\]

Each output embedding incorporates information from **all tokens in the sequence**.

---

## Step-by-Step: Naive Self-Attention (No Trainable Parameters)

For a word \( v_i \):

### Step 1: Compute Dot Products (Similarity Scores)

\[
s_{ij} = v_i \cdot v_j
\]

These scores measure how much word \( j \) should influence word \( i \).

---

### Step 2: Normalize with Softmax

\[
w_{ij} = \text{softmax}(s_{ij})
\]

- All weights sum to 1.
- These are called **attention weights**.
- ⚠️ They are **not trainable parameters** — they are derived values.

---

### Step 3: Weighted Sum

\[
y_i = \sum_j w_{ij} v_j
\]

The new embedding \( y_i \) is a contextualized version of \( v_i \).

---

## Properties of Self-Attention

- **Global context:** Every word attends to every other word.
- **Position-agnostic:** Order does not matter (fixed later via positional encoding).
- **Parallelizable:** All tokens processed simultaneously.
- **Shape independent:** Works for variable-length sequences.

---

# 3. Adding Trainable Parameters: Queries, Keys, Values

To allow learning, introduce matrices:

- \( W_Q \): Query matrix  
- \( W_K \): Key matrix  
- \( W_V \): Value matrix  

If embedding \( v \in \mathbb{R}^{1 \times k} \):

\[
Q = v W_Q
\]
\[
K = v W_K
\]
\[
V = v W_V
\]

---

## Scaled Dot-Product Attention

\[
\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
\]

Where:
- \( QK^T \) = similarity scores
- \( d_k \) = key dimension
- Scaling prevents large dot products and vanishing gradients

---

# 4. Multi-Head Attention

Instead of one attention mechanism, use **H parallel heads**.

For each head \( i \):

\[
\text{head}_i = \text{Attention}(QW_Q^{(i)}, KW_K^{(i)}, VW_V^{(i)})
\]

Then:

\[
\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \dots, \text{head}_H) W_O
\]

## Benefits
- Different heads learn different relationships:
  - Syntax
  - Coreference
  - Long-range dependencies
- Greater expressive power.

---

# 5. Self-Attention vs Cross-Attention

## Self-Attention
- Operates within a single sequence.
- Used in encoders and decoders.

## Cross-Attention
- Queries from one sequence.
- Keys and values from another.
- Used in encoder-decoder models (e.g., translation).

---

# 6. Transformer Architecture

From *Attention Is All You Need* (Vaswani et al., 2017).

---

## Encoder Block

Each layer contains:

1. **Multi-Head Self-Attention**
2. **Add & LayerNorm**
3. **Feedforward Network (FFN)**
4. **Add & LayerNorm**

### Residual Connection
\[
Y = F(X) + X
\]

Prevents vanishing gradients (similar to ResNet).

---

## Positional Encoding

Attention does not encode order.

Original sinusoidal encoding:

\[
PE(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)
\]
\[
PE(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)
\]

- Added element-wise to embeddings.
- Alternatives: learned embeddings, Rotary Positional Embeddings (RoPE).

---

## Decoder Block

Contains:

1. **Masked Self-Attention**
   - Prevents attending to future tokens.
2. **Cross-Attention**
   - Attends to encoder outputs.
3. **Feedforward Network**
4. **Output projection + Softmax**

---

## Masking Mechanism

Future tokens receive:

\[
-\infty
\]

before softmax → probability ≈ 0.

---

## Training Objective

For generation tasks:

- Predict next token.
- Use **cross-entropy loss**.

---

# 7. Transformer Variants

| Model | Architecture | Direction | Use Case |
|--------|-------------|-----------|----------|
| **BERT** | Encoder-only | Bidirectional | Classification, NER |
| **GPT** | Decoder-only | Autoregressive | Text generation |
| **BART / T5** | Encoder-decoder | Seq2seq | Summarization, translation |

---

## BERT

- **MLM (Masked Language Modeling)**
- **NSP (Next Sentence Prediction)**
- Strong for understanding tasks.

---

## GPT

- Next-token prediction.
- Autoregressive.
- Used for generation.

---

## BART

- Denoising autoencoder.
- Encoder (bidirectional) + decoder (causal).
- Excellent for summarization.

---

# 8. Inference Process

1. Tokenize input.
2. Convert tokens to embeddings.
3. Add positional encodings.
4. Pass through transformer layers.
5. Decoder generates token probabilities.
6. Select most likely token.
7. Repeat until termination.

Embeddings are **dynamic**:
- “orange” (fruit) vs “orange” (color)
- Meaning depends on context.

---

# 9. Computational Considerations

## Complexity
Attention is:

\[
O(n^2)
\]

Where \( n \) = sequence length.

## Challenges
- Memory consumption
- Long context inefficiency

## Optimizations
- Sparse attention (Longformer, BigBird)
- Gradient checkpointing
- Mixed precision
- Specialized GPUs

# 10. Applied NLP

---

## A. Text Similarity

### Types
- **Lexical similarity**
- **Semantic similarity**

### Cosine Similarity

\[
\text{sim}(A,B) = \frac{A \cdot B}{||A|| \, ||B||}
\]

Range: [-1, 1]

Limitations:
- No absolute threshold
- Assumes linear relationships

---

## B. Text Summarization

### Extractive
- Select sentences from source.
- Example: TextRank (graph-based, PageRank).

### Abstractive
- Generate new summary text.
- Uses transformer models (BART, T5).

---

## Evaluation Metrics

### ROUGE
- ROUGE-1 (unigram overlap)
- ROUGE-2 (bigram overlap)
- ROUGE-L (longest common subsequence)

Surface-level metric.

---

### BERTScore
- Uses contextual embeddings.
- Better semantic matching.

---

### NLI-Based Factual Consistency

- Premise = source document
- Hypothesis = summary sentence
- Labels: entailment / neutral / contradiction
- Detects hallucinations.

---

## C. Topic Modeling

### Traditional
- **LSA**
- **LDA**

### Modern
- Transformer embeddings + clustering
- Compare word embeddings to document embedding
- Keywords = highest cosine similarity

# 13. Multimodal Transformers

Anything tokenizable can use transformers.

---

## Vision Transformer (ViT)

- Split image into 16×16 patches.
- Each patch = token.
- Add positional encoding.
- Apply transformer.

---

## CLIP

- Image encoder + text encoder.
- Train via contrastive loss.
- Shared embedding space.

Loss:

\[
\text{loss} = \frac{loss_i + loss_t}{2}
\]

Used in:
- Zero-shot classification
- Diffusion models

---

# 14. Mixture of Experts (MoE)

Traditional transformer:
- All parameters active.

MoE:
- Router selects subset of expert networks.
- Improves efficiency.
- Scales better.
