# Linear Regression and Regularization

## 1. What Is a Linear Model?

A **linear model** is a model that is **linear in its parameters (weights)**, not necessarily linear in the input variables.

- A model is linear if it can be written as:

\[
y = w_0 + w_1 \phi_1(x) + w_2 \phi_2(x) + \dots + w_p \phi_p(x)
\]

- The functions \( \phi_i(x) \) can be nonlinear (e.g., \( x^2 \), \( \log x \), interaction terms).
- The key requirement: **weights \( w_i \) appear linearly (no products or nonlinear functions of weights).**

### Important Distinction
- Linear ≠ straight line
- Linear = linear in coefficients

---

## 2. Why Care About Linear Regression?

Linear regression is:

- A **foundation** of many machine learning models
- A **strong baseline**
- **Fast to train**
- **Highly interpretable**
- Useful for understanding feature–target relationships

**Best practice:** Always try linear regression first as a benchmark model.

---

## 3. Simple vs. Multiple Linear Regression

### Simple Linear Regression
One feature:

\[
y = w_0 + w_1 x
\]

### Multiple Linear Regression
Multiple features:

\[
y = w_0 + w_1 x_1 + w_2 x_2 + \dots + w_p x_p
\]

### Interpretation

- **\( w_0 \)**: Intercept (expected value of \( y \) when all \( x_i = 0 \))
- **\( w_i \)**: Change in \( y \) per unit increase in \( x_i \), holding other variables constant

Note: “Holding other variables constant” can be unrealistic if features are correlated.

---

## 4. Estimating Parameters

### Goal

Minimize the **Sum of Squared Errors (SSE)**:

\[
J(w) = \sum_{i=1}^{N} (y_i - \hat{y}_i)^2
\]

We cannot change:
- Inputs \( X \)
- Outputs \( y \)

We can only adjust:
- Parameters \( w \)

---

### Vectorized Form

For multiple observations:

\[
\hat{y} = X w
\]

- \( X \in \mathbb{R}^{N \times (p+1)} \)
- \( w \in \mathbb{R}^{(p+1) \times 1} \)

Cost function:

\[
J(w) = (y - Xw)^T (y - Xw)
\]

---

## 5. Closed-Form Solution (Normal Equation)

Set derivative to zero:

\[
w = (X^T X)^{-1} X^T y
\]

### Limitations
- Requires matrix inversion
- Computationally expensive for large feature sets
- Rarely used in practice for large-scale problems

---

## 6. Gradient Descent

Instead of closed form:

- Iteratively update weights
- Scales better for large datasets
- Used in most ML algorithms

---

## 7. Assumptions of Linear Regression

1. **Linearity**: Expected value of \( y \) is linear in inputs
2. **Errors are independent**
3. **Homoscedasticity**: Constant variance of errors
4. **No multicollinearity**: Features not highly correlated

Violations do not invalidate the model, but may reduce interpretability and performance.

---

## 8. Diagnosing Assumptions

### Linearity

- Scatterplot \( y \) vs. \( x \)
- Residual plot

Residuals should:
- Be centered around 0
- Show no pattern

---

### Heteroscedasticity

Residual variance changes with prediction.

- Funnel-shaped residual plot → problem
- Suggests transforming target (e.g., log)

---

### Multicollinearity

Highly correlated features cause:

- Unstable coefficients
- Large swings in weights
- Sign flipping
- Poor interpretability

Detection:
- Correlation matrix

Important:
- May not hurt prediction
- Hurts interpretation

---

## 9. Handling Violations

### Nonlinearity
- Transform features
- Add polynomial terms

### Non-constant variance
- Transform target (log, sqrt)

### Multicollinearity
- Remove features
- Apply regularization

Always inspect residual plots.

---

## 10. Polynomial Regression

Add higher-degree terms:

\[
y = w_0 + w_1 x + w_2 x^2 + w_3 x^3
\]

Still linear in coefficients.

### Tradeoff
- Higher degree → more flexibility
- Risk of overfitting

Choose degree via **cross-validation**.

---

## 11. Interaction Terms

Linear regression assumes independent feature effects.

But real-world features often interact:

Example:
- Wind speed × Rainfall in outage prediction

Model with interaction:

\[
y = w_0 + w_1 x_1 + w_2 x_2 + w_3 (x_1 x_2)
\]

Generated automatically using `PolynomialFeatures`.

# Regularization

## 12. Motivation

Minimizing SSE alone rewards complexity:

- More features → lower training error
- Leads to overfitting
- High variance

### Solution

Add penalty term:

\[
J(w) = \text{SSE} + \lambda \cdot \text{Penalty}
\]

Balances:
- Fit quality
- Model simplicity

---

## 13. Ridge Regression (L2)

Penalty:

\[
\lambda \sum w_i^2
\]

Effects:
- Shrinks coefficients
- Does not set them to zero
- Good for multicollinearity
- More stable solutions

---

## 14. LASSO Regression (L1)

Penalty:

\[
\lambda \sum |w_i|
\]

Effects:
- Drives some coefficients exactly to zero
- Performs feature selection
- Produces sparse models

---

## 15. Geometric Intuition

### LASSO
- Diamond constraint region
- Corners encourage zero coefficients
- Produces sparse solutions

### Ridge
- Circular constraint region
- Smooth shrinkage
- Rarely produces exact zeros

---

## 16. Lambda (λ)

Hyperparameter controlling penalty strength:

- Low λ → complex model
- High λ → simpler model

Choose λ using:
- Validation set
- Cross-validation

Best practice:
- Search across orders of magnitude
- Then refine search

Always scale features before applying L1/L2.

---

## 17. LASSO vs Ridge

### Choose LASSO if:
- Interpretability important
- Feature selection desired

### Choose Ridge if:
- Many correlated features
- Performance more important than sparsity

If unsure: try both.

---

# Classification Metrics (From Earlier Section)

## 18. Accuracy Limitations

Accuracy is misleading under class imbalance.

Example:
- Rare disease detection
- Predict all negatives → high accuracy
- Model useless

---

## 19. Confusion Matrix

Components:

- True Positive (TP)
- False Positive (FP)
- True Negative (TN)
- False Negative (FN)

---

## 20. Key Metrics

### Recall (Sensitivity, TPR)

\[
\text{Recall} = \frac{TP}{TP + FN}
\]

Out of all actual positives, how many were identified?

---

### Precision

\[
\text{Precision} = \frac{TP}{TP + FP}
\]

Out of predicted positives, how many were correct?

---

### Tradeoff

- Increasing recall often lowers precision
- Choose metric based on domain

Fraud detection → prioritize recall  
Medical diagnosis confirmation → prioritize precision

---

## 21. ROC Curve

Plot:
- True Positive Rate vs False Positive Rate
- Across varying thresholds

Area Under Curve (AUC):
- Summary metric
- Higher = better

---

## 22. Precision–Recall Curve

Preferred when:
- Classes highly imbalanced

Why?
- Does not reward true negatives excessively

---

## 23. F1 Score

\[
F1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
\]

- Harmonic mean of precision and recall
- Used frequently in research
- Assumes equal importance of both

Often less practical in industry where one metric dominates.

---

# Final Takeaways

- Linear regression remains a powerful baseline.
- Interpretability is a major advantage.
- Diagnose using residual plots and correlation analysis.
- Improve with:
  - Polynomial terms
  - Interaction terms
  - Regularization
- Tune hyperparameters using cross-validation.
- Use confusion matrices and ROC/PR curves for classification evaluation.
- Choose regularization method based on goals (sparsity vs stability).

Even in the deep learning era, linear regression remains:
- Foundational
- Interpretable
- Computationally efficient
- Often surprisingly effective
