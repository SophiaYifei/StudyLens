What is Machine Learning?
	•	Learning from experience
	•	Task-based vs generalization
	•	No explicit rule coding
	•	Pattern extraction from data
Question
	•	Is my model learning patterns or memorizing?

Why ML?
	•	Automation benefit
	•	Rules too complex
	•	Unknown rule structure
	•	Scalability need
Reflection
	•	Could heuristics solve this instead?

What is a Model?
	•	Approximation of reality
	•	y = f(x) + error
	•	Parameters compress knowledge
	•	Inputs (features) → Outputs (targets)
Key idea
	•	All models wrong, some useful

Supervised vs Unsupervised
	•	Supervised → X + Y known
	•	Unsupervised → only X
	•	Regression = numeric
	•	Classification = categorical
Practice Thought
	•	Stock price → regression
	•	Fake news detection → classification

Heuristics vs ML
	•	Heuristics = simple rules
	•	ML = adaptable, scalable
	•	Heuristics baseline important
To-Do
