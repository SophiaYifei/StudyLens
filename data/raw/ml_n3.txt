What is a Linear Model?
	•	Linear in parameters (w)
	•	Can model nonlinear relationships via transformations
	•	Linear ≠ straight line always
	•	Linear in coefficients
Question
	•	What makes a model “linear”? The inputs or the parameters?

Why Care About Linear Regression?
	•	Foundation of many ML models
	•	Simple, interpretable
	•	Strong baseline model
	•	Fast to train
	•	Helps understand feature relationships
To-Do
	•	Always try linear regression first as benchmark

Simple vs Multiple Linear Regression
Simple:
	•	One feature
	•	y = w₀ + w₁x
Multiple:
	•	Multiple features
	•	y = w₀ + w₁x₁ + w₂x₂ + ...
Question
	•	What changes when adding more features?
	•	Interpretation more complex?

Model Interpretation
	•	w₀ → intercept
	•	wᵢ → change in y per unit change in xᵢ
	•	Hold other variables constant
Reflection
	•	Does “holding constant” make sense in real data?

Estimating Parameters
Goal:
	•	Minimize SSE
Options:
	•	Closed-form (Normal equation)
	•	Gradient descent
Closed form:
	•	Matrix inverse
	•	Computationally heavy for large data
Gradient descent:
	•	Iterative
	•	Scales better
Question
	•	When would closed-form be impractical?

Assumptions of Linear Regression
	1	Linearity
	2	Errors independent
	3	Constant variance (homoscedasticity)
	4	No multicollinearity
Violations → poor interpretation

Checking Assumptions
Linearity
	•	Scatterplot y vs x
	•	Residual plot
Residuals:
	•	Should center around 0
	•	No pattern

Heteroscedasticity
	•	Residual variance changes with predictions
	•	Funnel shape = problem
Question
	•	Why is non-constant variance an issue?

Multicollinearity
	•	Highly correlated features
	•	Coefficients unstable
	•	Hard to interpret
Detection:
	•	Correlation matrix
Important
	•	May not hurt prediction much
	•	Hurts interpretation

What If Assumptions Violated?
Non-linearity:
	•	Transform features
	•	Add polynomial terms
Non-constant variance:
	•	Transform target (log, sqrt)
Collinearity:
	•	Remove features
	•	Regularization
To-Do
	•	Always inspect residual plots

Polynomial Regression
	•	Add higher-degree terms
	•	Still linear in coefficients
	•	Increase model complexity
Degree 1 → linear Degree 3 → more flexible
⚠ Risk of overfitting
Question
	•	How to choose polynomial degree?
To-Do
	•	Use cross-validation

Interaction Terms
	•	Feature synergy
	•	Effect of one feature depends on another
Example:
	•	Wind × Rain
Can generate via:
	•	PolynomialFeatures
Reflection
	•	Which features likely interact in your dataset?

Regularization Motivation
Problem:
	•	SSE minimization rewards complexity
	•	Complex model → low train error
	•	High variance
Solution:
	•	Add penalty term
Goal:
	•	Balance fit + simplicity

Ridge Regression (L2)
	•	Penalize squared coefficients
	•	Shrinks coefficients
	•	Does NOT set to zero
	•	Good with collinearity
Penalty:
	•	λ Σ w²

LASSO Regression (L1)
	•	Penalize absolute coefficients
	•	Produces sparse solutions
	•	Performs feature selection
Penalty:
	•	λ Σ |w|

Geometric Intuition
LASSO:
	•	Diamond constraint
	•	Intersects at corners
	•	Many coefficients = 0
Ridge:
	•	Circular constraint
	•	Coefficients small but rarely zero

Lambda (λ)
	•	Hyperparameter
	•	Low λ → complex model
	•	High λ → simpler model
Choose via:
	•	Validation set
	•	Cross-validation
To-Do
	•	Always scale before L1/L2
	•	Tune λ using CV
LASSO vs Ridge Decision
Choose LASSO if:
	•	Want simpler model
	•	Feature selection important
Choose Ridge if:
	•	Many correlated features
	•	Complex target relationships
If unsure:
	•	Try both

Wrapping Up Linear Regression
