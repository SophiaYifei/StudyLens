	•	Predict categorical target
	•	Binary or multiclass
	•	Examples:
	◦	Handwritten digits
	◦	Tumor type
	◦	Disease category
	◦	Next word prediction
	•	Can bin numeric variables into classes
	•	Cannot extrapolate beyond classes

Why Not Use Linear Regression for Classification?
	•	Outputs not constrained between 0 and 1
	•	Hard to interpret probabilities
	•	Predictions may exceed logical bounds
	•	Poor classification performance
Question
	•	What happens if model predicts 1.7 for a class label?

Logistic Regression – Core Idea
	•	Predict probability P(y=1)
	•	Use sigmoid function
	•	Input = linear combination of features
	•	Output between 0 and 1
Sigmoid
	•	S-shaped curve
	•	Maps real numbers to probability
Decision rule
	•	Apply threshold (default 0.5)
	•	Probability ≥ threshold → class 1
Question
	•	How would changing threshold affect precision and recall?

Parameter Estimation
	•	Cannot use SSE
	•	Use maximum likelihood estimation
	•	Define likelihood of observing data
	•	Maximize log-likelihood
	•	Equivalent to minimizing negative log likelihood
No closed-form solution
	•	Use gradient descent
	•	Iterative optimization

	•	Why is log-likelihood preferred over likelihood?

Gradient Descent
	•	Move opposite direction of gradient
	•	Learning rate controls step size
	•	Too small → slow convergence
	•	Too large → divergence

Multiclass Classification – Softmax
	•	One weight vector per class
	•	Compute score for each class
	•	Apply softmax to normalize
	•	Probabilities sum to 1
	•	Choose class with highest probability
Cost function
	•	Cross entropy
Binary case
	•	Equivalent to logistic regression

	•	Why use cross entropy instead of SSE?

K Nearest Neighbors (KNN)
	•	Instance-based method
	•	No explicit model training
	•	Assign class based on nearest neighbors
	•	k = hyperparameter
Choices
	•	Value of k
	•	Distance metric
	•	Feature scaling
Small k
	•	Low bias
	•	High variance
	•	Risk overfitting
Large k
	•	Higher bias
	•	Smoother boundary
Question
	•	Why must we scale features for KNN?
To-Do
	•	Test k = 1 vs k = 5 vs k = 15
	•	Compare validation accuracy
Limitations
	•	Computationally expensive
	•	Memory intensive
	•	Not ideal for large datasets

Support Vector Machines (SVM)
	•	Can do classification and regression
	•	Often used for classification
	•	Strong theoretical foundation
	•	Convex optimization problem
Core idea
	•	Find separating hyperplane
	•	Maximize margin between classes
Support vectors
	•	Points closest to margin
	•	Determine decision boundary
	•	Other points irrelevant
Question
	•	Why focus only on support vectors?
To-Do
	•	Visualize margin in 2D example

Soft Margin SVC
	•	Data not perfectly separable
	•	Allow misclassification
	•	Tradeoff between margin width and errors
Hyperparameter C
	•	Large C → smaller margin, fewer training errors
	•	Small C → wider margin, more tolerance
Interpretation
	•	C controls model complexity
Question
	•	Which C likely generalizes better? Large or small?

	•	Use cross-validation to tune C

Kernel Trick
	•	Map data to higher-dimensional space
	•	Make non-linear boundaries linear in new space
Common kernels
	•	Linear
	•	Polynomial
	•	Radial Basis Function (RBF)
Polynomial kernel
	•	Adds polynomial interactions
RBF kernel
	•	Uses distance from landmarks
	•	Flexible decision boundary

SVC Pros and Cons
Advantages
	•	Flexible with kernels
	•	Works well in high dimensions
	•	Convex optimization
Disadvantages
	•	Slow for large datasets
	•	Often outperformed by tree ensembles or neural networks
	•	No native probabilistic output
Best suited for
	•	“Short and fat” datasets
	•	High feature dimension
