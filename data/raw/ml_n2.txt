	•	Training set → build model
	•	Test set → final evaluation
	•	Typical split:
	◦	80–90% training
	◦	10–20% testing
⚠ Test set = untouched until final

📦 Sampling
Why Sample?
	•	Cannot access full population
	•	Too expensive to process everything
	•	Sampling happens multiple times

Types of Sampling
Nonprobability Sampling
	•	Convenience
	•	Snowball
	•	Judgment
	•	Quota
⚠ High risk of bias
Examples:
	•	LLM trained on Reddit/Wikipedia
	•	IMDB sentiment bias
	•	Self-driving car location bias
Question
	•	Does your dataset reflect real-world distribution?

Random Sampling
	•	Simple random
	•	Stratified sampling
	•	Weighted sampling
Stratified → preserve class proportions
Weighted → emphasize certain data (e.g., recent data)
To-Do
	•	Use stratify for imbalanced classification

🚨 Data Leakage
Definition:
	•	Test information leaks into training
Consequences:
	•	Inflated performance
	•	Over-optimistic results
	•	Useless model in production

Common Leakage Sources
	•	Feature selection before split
	•	Scaling before split
	•	Imputing before split
	•	Duplicate observations
	•	Future data in training
	•	Random split in time series
Question
	•	Why is random split bad for time series?
To-Do
	•	Split first
	•	Fit preprocessing on training only

📊 Model Comparison
Why Not Use Test Set?
	•	Becomes biased
	•	Overfits to test set
Solution:
	•	Train / Validation / Test split
Typical:
	•	60–80% training
	•	10–20% validation
	•	10–20% test

Validation Set Risks
	•	Small validation set → noisy estimate
	•	Model selection bias
	•	Repeated tuning = indirect leakage
Question
	•	What happens if validation set too small?

🔁 Cross-Validation
K-Folds
	•	Divide into K folds
	•	Train on K-1
	•	Validate on 1
	•	Repeat K times
	•	Average error
Benefits:
	•	More stable performance estimate
	•	Uses more data

Other CV Types
	•	ShuffleSplit
	•	Leave-One-Out
Tradeoff:
	•	More folds → higher compute
To-Do
	•	Use 5-fold or 10-fold CV by default

⚖ Bias-Variance Tradeoff
Bias:
	•	Model too simple
	•	Underfitting
Variance:
	•	Model too complex
	•	Overfitting
Total Error:
	•	Bias² + Variance + Irreducible error

Recognizing Overfitting
	•	Training score ↑
	•	Validation score ↓
	•	Divergence
Question
	•	Does more features always improve performance?

🎯 Model Complexity Influenced By
	•	Algorithm choice
	•	Number of features
	•	Hyperparameters
	•	Amount of data
More data → tolerate more complexity

📊 Regression Metrics
MSE:

	•	Sensitive to outliers
MAE:
	•	More robust

	•	Percentage error
	•	Biased when y small
R²:
	•	Variance explained
	•	In-sample metric
Adjusted R²:
	•	Penalizes extra features
Question
	•	When is MAE better than MSE?

🧮 Classification Metrics
Accuracy:
	•	Misleading with imbalance
Confusion Matrix:
	•	TP
	•	FP
	•	TN
	•	FN
Recall (TPR):
	•	Of actual positives, how many found?
Precision:
	•	Of predicted positives, how many correct?
FPR:
	•	Of actual negatives, how many mislabeled?

Edge Case Thought
Model predicts all positive:
	•	Recall = high
	•	FPR = high
	•	Precision = low

📉 ROC Curve
	•	TPR vs FPR
	•	Threshold variation
	•	Default threshold = 0.5
Higher threshold:
	•	Lower TPR
	•	Lower FPR
Lower threshold:
	•	Higher TPR
	•	Higher FPR
AUROC:
	•	0.5 = random
	•	1 = perfect

📊 Precision-Recall Curve
	•	Better for imbalanced data
	•	Ignores TN
Question
	•	When should PR curve preferred over ROC?

🧠 Multiclass Evaluation

	•	Macro average
